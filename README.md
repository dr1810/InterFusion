# InterFusion
Problem Statement
• Current the current multimodal architectures often process different
modalities (such as text, images and audio) separately and fuse them
in a later stage.
• The approach may not fully leverage and learn from the potential
interactions between the modalities which may hinder learning more
complex and insightful patterns.
• To build a unified network that simultaneous learning and interaction
between the modalities to improve learning and understanding of
more complex patterns and relationships between the modalities.
